# Little World

Private source backup of the current local development build. This is not a release or a live deployment.

## Run locally

Requires Node.js 18 or newer.

```sh
npm install
npm start
```

The default server is at http://localhost:8787. Without DATABASE_URL, development storage starts in a local data.json file. Do not commit that file. No production database, credentials or player records are included.

## Development status

The game is a work in progress. Source-geography prototypes, visual changes and gameplay need further validation. Device frame rate and real-phone behavior are not qualified. Third-party geography and asset rights have not been cleared for public redistribution or release. Keep this repository private.

Prague is a local prototype; its geography, world scale and collision model are schematic. Development files do not grant real-world access. Existing live-game saves and state are not included or changed by this backup.
